# Confirmatory experiment outputs

Validated E00-E10 experimental runs are written to `results/confirmatory/<experiment_id>/<config_sha256>/` according to `.claude/skills/bayesbreak-release-audit/references/experiment_protocols.md`. No E00-E10 run has been completed in this distribution. Existing figure assets from earlier completed analyses, with limitations and rerun decisions, are in `docs/manuscripts/shared/figures/results/` and `.claude/RESULT_POLICY.md`. The directory is otherwise empty to avoid distributing obsolete raw run histories.
