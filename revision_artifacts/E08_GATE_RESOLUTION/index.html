    E08 Gate Resolution: Posterior Prediction¶

    Date: 2026-10-24 Status: PASS (corrected run, protocol revision 2026-10-24-2)

    1. Original contaminated run (cc26eda02dc82357)¶

    Protocol revision 2026-10-24-1. Three defects were found during A-checks:

    1. BayesBreakBetaObs._compute_block_evidence did not apply likelihood_power_; holdout observations entered the DP block evidence matrix and contaminated the MAP segmentation and posterior moments for BetaObs cells.
    2. BayesBreakBetaObs.posterior_predictive_logpdf_block and BayesBreakBetaObs._segment_posterior_mean called _segment_posterior_log_weights with raw sample_weight_ instead of lp * sample_weight_.
    3. prediction._segment_pit for BetaObs called _segment_posterior_log_weights with raw sample_weight_; for Binomial it computed training S and N without the lp[a:b] factor.

    None of the non-BetaObs families (Gaussian, Poisson, Binomial) were affected by defects 1-2. Defect 3 (Binomial PIT) produced biased PIT statistics in the old run.

    2. Fixes applied (all in production code, no protocol change)¶

    File Change
    src/bayesbreak/families/beta_obs.py _compute_block_evidence: add a_lp = likelihood_power_, w = a_lp * w before prefix sums
    src/bayesbreak/families/beta_obs.py posterior_predictive_logpdf_block: pass lp * sample_weight_ to _segment_posterior_log_weights
    src/bayesbreak/families/beta_obs.py _segment_posterior_mean: pass lp * w to _segment_posterior_log_weights
    src/bayesbreak/prediction.py BetaObs _segment_pit: pass lp * estimator.sample_weight_ to _segment_posterior_log_weights
    src/bayesbreak/prediction.py Binomial _segment_pit: compute S = sum(lp * w_train * y_train), N = sum(lp * w_train * n_train)

    3. A-check results¶

    A1: likelihood_power_ regression tests¶

    Six new tests added to tests/test_observation_mask.py:

    • TestBetaObsLikelihoodPower.test_block_evidence_masked_equals_observed_only
    • TestBetaObsLikelihoodPower.test_block_evidence_differs_from_unmasked_full_fit
    • TestBetaObsLikelihoodPower.test_predictive_logpdf_masked_matches_observed_only
    • TestBetaObsLikelihoodPower.test_pit_masked_matches_direct_fit_on_observed_subset
    • TestBinomialPITLikelihoodPower.test_masked_pit_matches_direct_fit_on_observed_subset
    • TestBinomialPITLikelihoodPower.test_posterior_parameters_exclude_masked_obs

    All pass. Total suite: 952 passed, 4 skipped.

    Binomial w in _segment_pit is the per-prediction n_trials (same semantic as posterior_predictive_logpdf_block(w_new=n_trials)), not sample_weight or likelihood power. The lp factor applies to the TRAINING posterior S and N, not to the new-observation n_trials.

    A2: NegBin moments¶

    First moment: E[m_*] = r_* * b_post / (a_post - 1) requires a_post > 1. Reports nan when a_post <= 1 (four existing tests in TestA2NegBinDivergentMoment).

    Second moment: E[m_*^2] = r_*^2 * b_post * (b_post + 1) / ((a_post - 1) * (a_post - 2)) requires a_post > 2. Not currently computed or stored. Three new tests added to TestA2NegBinDivergentMoment: - test_second_moment_not_stored: confirms no block_second_moment_ attribute. - test_second_moment_formula_valid_above_two: formula is positive finite for a_post > 2. - test_second_moment_formula_diverges_at_a_post_le_2: denominator is zero at a_post = 2, negative at a_post = 1.5.

    Comment added to negative_binomial.py near the E[m_*] computation.

    The old results were inflated by data leakage: holdout observations entered the segment posterior, making the predictive artificially accurate. The corrected results show genuine under-coverage (76-77%) in both BetaObs cells, attributable to MAP-conditional prediction not accounting for partition uncertainty and to holdout windows crossing true segment boundaries (windows 1 and 2 span the boundaries at positions 40 and 80 for n=120).

    Scientific interpretation¶

    • Identifiable effects (CI entirely positive): Gaussian delta=1.5, Poisson q=3.0, Binomial p_mid=0.65, BetaObs mu_mid=0.4 and mu_mid=0.8. Fitted model beats null.
    • Unidentifiable / weak effects (CI entirely negative): Gaussian delta=0.5, Poisson q=1.5. Over-segmentation or under-segmentation degrades held-out predictive density.
    • Borderline (CI includes zero): Binomial p_mid=0.35.
    • BetaObs coverage: 76-77% (vs nominal 95%). MAP-conditional predictive does not account for partition uncertainty; genuine boundary-crossing effect. Both families are far better than null (14.7% and 64.6% coverage), confirming the fitted model is structurally superior.
    • Gaussian coverage (delta=1.5): 87.6%, below nominal 95%. Same MAP-conditional issue; consistent with the prior analysis.
