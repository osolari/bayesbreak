    2. Model parameters¶

    Robust noise estimate. sigma2 for Gaussian fits estimated via median-absolute-deviation of first differences: sigma = 1.4826 * median(|diff(y) - median(diff(y))|) / sqrt(2).

    Dataset sigma2 (robust MAD-diff)
    welllog full 4,674,808.19
    welllog stride-8 5,466,698.12
    CGH (pooled across 43 subjects) 0.0057

    Hyperparameter strategy.

    • welllog: estimate_hyper=True with fixed sigma2. BayesBreakGaussian estimates nu (weighted mean of y) and rho2 (variance of y) from data. Required because welllog values are ~10^5 NMR units; a fixed prior of nu=0, rho2=4.0 places the prior far from the data, collapsing evidence to k_map=1 (see Section 3).
    • CGH: fixed nu=0.0, rho2=4.0. Appropriate for log2-ratio data (neutral copy number at 0, typical CNV excursions up to ±2). Shared prior across 43 subjects.
    • methylation: BetaObs family; hyperparameters estimated by the family from data.

    Count priors. geometric_decay_log4 and uniform tested on all primary fits.

    BetaObs quadrature. 128 Gauss-Legendre nodes (confirmed sufficient in E08 A4).

    CGH pooling. SharedBoundaryReplicatesSegmenter pools 43 subjects: block log-evidences from each subject are summed before the DP; one shared MAP boundary vector is returned.

    k_max grid. Primary: {15, 30, 60}. Extended for truncation resolution: - welllog full: up to k_max=100 - welllog stride-8: k_max=60 - CGH single_subject0: up to k_max=100 - methylation: up to k_max=120 (truncation not resolved)

    3. Fixes applied before the canonical run¶

    Two correctness defects found and fixed during script development. Both affected the superseded run (config SHA256 prefix bae816ac60300df3).

    Fix 1: _min_len_prior returned 0.0 for valid segments¶

    base.py checks if value > 0 and np.isfinite(value). Returning 0.0 caused valid segments to receive -inf in the log-g table. All minimum-length sensitivity cells failed. Fix: return 1.0 for valid segments (log(1.0) = 0.0, no additive penalty), 0.0 for invalid segments (fails > 0 check, assigned -inf).

    Fix 2: Wrong Gaussian prior for welllog¶

    The superseded run used nu=0, rho2=4.0 for welllog. Welllog NMR values are ~10^5; the prior was far from the data. All welllog cells returned k_map=1. Fix: estimate_hyper=True for welllog, letting the model estimate nu and rho2 from data while fixing sigma2 to the robust MAD-diff estimate.

    4. Truncation criterion¶

    A cell is reported truncated if k_map == k_max OR P(k=k_max|y) >= 0.01. Truncation means substantial posterior mass lies at or above k_max; the unrestricted MAP segment count is unknown. Do not extrapolate a MAP value from a truncated posterior.

    6. Boundary marginals¶

    The BayesBreak DP provides exact boundary-event marginals (boundary_marginals_) and boundary location posteriors (boundary_location_posterior_) after fitting, conditional on the MAP segment count. No Markov chain Monte Carlo or variational approximation is required. These are stored as fitted attributes and can be queried for any resolved configuration.

    For truncated configurations, boundary marginals conditional on k_map are available but should be interpreted with caution: they condition on a segment count that may not be the unrestricted MAP, and they reflect the boundary distribution within the constrained model support. These are not marginals under the unrestricted model.

    Detailed boundary-marginal summaries for the resolved configurations (welllog full geometric_decay_log4 k_max=100, welllog stride-8, welllog min_seg sensitivity, CGH single_subject0) are reported in E09_SCIENTIFIC_STATUS.md.

    8. SPX exclusion¶

    load_spx() returned a simulated fallback (yfinance not installed). Per protocol and standing constraint: never label simulated data as genuine observational data. SPX is excluded from E09. It is not counted in any result table.

    9. Scientific findings from resolved configurations¶

    Welllog (primary: geometric_decay_log4, k_max=100)¶

    The full welllog series (n=4050) has MAP segment count 83 (82 internal changepoints) under the geometric-decay prior. The stride-8 subsampled series (n=507) has MAP segment count 25 (24 internal changepoints). These are the model's segment-count estimates under the respective observation sequences; no claim is made about structural information content or about which changepoints from the full series are absent in the subsampled result.

    Minimum segment length sensitivity: enforcing min_seg=5 gives k_map=61; min_seg=10 gives k_map=56. Both are resolved. The corresponding log-evidence values (-38163.8 and -38854.7 vs -37906.1 for min_seg=1) reflect the model families with and without the segment-length constraint; they are not directly comparable as Bayes factors unless the partition prior normalizer is verified to be the same under each constraint.

    CGH¶

    The pooled MAP segment count is not resolved at any tested k_max. The single-subject analysis of subject 0 gives k_map=71 (70 internal changepoints) at k_max=100. No external genomic annotation verification was performed; all boundary positions are in probe-index coordinates. The subject 0 result is not a summary for all 43 subjects.

    Methylation¶

    The MAP segment count is not resolved at any tested k_max up to 120. Candidate drivers of the truncation include: high per-site read-count precision (max 818 reads), large number of CpG sites (n=1904), and the BetaObs model's ability to detect small differences under high precision. These are candidate explanations, not verified diagnoses.
