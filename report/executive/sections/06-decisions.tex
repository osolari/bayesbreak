\subsection{Minimum conditions for a defensible release}

A release suitable for external technical review should satisfy the following conditions.
\begin{enumerate}
  \item The author-approved title and generalized hierarchical Bayesian segmentation narrative remain unchanged.
  \item All theorem-like statements used as established results have complete proofs; the routine-specific nonconjugate rate remains labeled as a proof obligation unless proved.
  \item The implementation corrections in Stages S1--S4 are complete or any incomplete item is explicitly removed from the affected claim.
  \item The invalid CGH comparator and methylation predictive calculation are not used unless corrected runs with new result IDs pass their statistical and schema checks.
  \item Every reported comparison states the reference set, tuning budget, coordinate axis, matching rule, repetitions, and uncertainty treatment.
  \item The book, main paper, executive summary, coding handoff, and presentation handoffs agree on terminology, notation, result status, and limitations.
\end{enumerate}
