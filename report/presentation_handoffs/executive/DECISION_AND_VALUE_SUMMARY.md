# Decision and value summary

## Research value

BayesBreak provides one generalized hierarchical Bayesian formulation for segmentation across supported exponential-family observation models, irregular coordinates, multiple related sequences, known groups, and finite latent groups. The same ordered-partition recursions are reused after each observation model supplies its segment marginal likelihoods.

## Current value already established

- Complete mathematical treatment of the exact finite partition recursions and joint MAP recovery.
- Hierarchical formulations for common partitions, known groups, and finite latent groups.
- Conditional propagation of segment approximation error to partition quantities.
- Real executed simulation and application outputs across several observation families.
- Corrected book and journal-paper sources under the SAIM template.

## Principal risks

- The finite latent-group final-objective defect can affect restart ranking.
- Beta posterior prediction and coordinate extrapolation are incomplete.
- Comparator-axis validation is incomplete, as demonstrated by the excluded CGH calculation.
- Seventeen bounded-run tests remain unresolved.
- External reference changepoints are unavailable for the application studies.
- Expanded repeated validation and fairness-controlled benchmarking remain incomplete.

## Decisions

1. Fund the minimum correction cycle through S5, or the complete validation and release program through S7.
2. Choose whether comparator work remains agreement analysis or becomes an external-accuracy benchmark with independent references.
3. Retain only the conditional nonconjugate theorem, or sponsor a separate method-specific rate project.
4. Retain the current finite latent-group criterion, or reserve a normalized probabilistic mixture for a future model.
5. Select the journal venue, permanent repository, and data/artifact location.
