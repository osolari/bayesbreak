
\paragraph{\texttt{carlin1992hierBayesCP}: \citet{carlin1992hierBayesCP}.}
Carlin, Gelfand, and Smith present hierarchical Bayesian changepoint analysis and show how uncertainty and pooling can be represented beyond a single flat partition model. BayesBreak uses this paper to locate its shared and grouped extensions within a broader hierarchical Bayesian lineage. The current exact BayesBreak results apply only where subject-level contributions factor through a common boundary vector or known grouping; richer hierarchical dependence generally requires additional computation. The source therefore informs both motivation and scope limits. \textit{Verification status: project metadata retained; supporting lineage.}
