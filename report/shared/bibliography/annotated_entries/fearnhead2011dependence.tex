
\paragraph{\texttt{fearnhead2011dependence}: \citet{fearnhead2011dependence}.}
Fearnhead and Liu develop efficient Bayesian multiple-changepoint analysis when parameters can depend across adjacent segments. BayesBreak's protected exact regime instead assumes that, after integration and declared prior factors, a partition score decomposes into local block contributions. This source marks a clear boundary: dependence across segments is scientifically useful but is not covered by the current exact block API without state augmentation or a different recursion. \textit{Verification status: primary source checked in Phase 1.}
