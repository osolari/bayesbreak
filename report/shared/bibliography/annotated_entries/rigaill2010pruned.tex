
\paragraph{\texttt{rigaill2010pruned}: \citet{rigaill2010pruned}.}
Rigaill develops pruned dynamic programming for recovering best segmentations over a range of segment counts. The work belongs to the optimization/pruning lineage and informs possible efficiency comparisons. BayesBreak's current core deliberately preserves the unpruned exact posterior recursion, so the empirical slopes near 1.07 and 1.14 are reported only as finite-range observations and never as a change to the $O(k_{\max}n^2)$ worst-case complexity. \textit{Verification status: published 2015 version recorded in the project bibliography.}
