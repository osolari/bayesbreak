
\paragraph{\texttt{polson2013pg}: \citet{polson2013pg}.}
Polson, Scott, and Windle introduce P\'olya--Gamma data augmentation for Bayesian logistic models, yielding conditional Gaussian structure. BayesBreak uses this identity as an established route for block-local logistic computation and diagnostics. The source does not imply that a mean-field or approximate BayesBreak block score has a uniform rate over all reachable blocks. Such a rate would require additional assumptions and proof; in this book the global theorem is explicitly conditional on a supplied local error certificate. \textit{Verification status: primary source checked in Phase 1.}
