
\paragraph{\texttt{olshen2004cbs}: \citet{olshen2004cbs}.}
Olshen and coauthors introduce circular binary segmentation for array-based DNA copy-number analysis. CBS is a domain-standard comparator for the array-CGH case study. It operates on point-estimate segmentation rather than BayesBreak's posterior partition distribution. The archived CGH comparator computation is excluded from scientific comparison because a $43\times2215$ fitted array was flattened to 95,245 values while the BayesBreak boundaries remained on the 2,215-probe axis; that execution cannot support a scientific comparison. \textit{Verification status: metadata retained; domain role and exclusion reason documented from the archive.}
