
\paragraph{\texttt{jackson2005optpart}: \citet{jackson2005optpart}.}
Jackson and coauthors give an algorithm for optimal partitioning of interval data, reinforcing the dynamic-programming lineage for globally optimal segmentations. BayesBreak uses this paper to distinguish an optimal partition computed by max-sum recursion from posterior quantities computed by sum-product recursion. Both routes consume the same local scores, but they answer different questions; marginal boundary modes cannot be substituted for the joint MAP partition. \textit{Verification status: metadata retained; algorithmic background.}
