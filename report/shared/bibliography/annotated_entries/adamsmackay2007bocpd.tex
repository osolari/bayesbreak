
\paragraph{\texttt{adamsmackay2007bocpd}: \citet{adamsmackay2007bocpd}.}
Adams and MacKay formulate online Bayesian changepoint detection through a recursive posterior over run length. BayesBreak uses this work to delimit its scope: BayesBreak is an offline contiguous-partition method that returns a posterior over segment count, fixed-count boundary marginals, Bayes curves, and a separate joint MAP partition, rather than an online filtering distribution. The source therefore informs the online/offline distinction and potential future streaming comparisons, but it is not treated as evidence for BayesBreak's offline exact-DP claims. \textit{Verification status: project bibliography metadata retained; role checked in the Phase 1 landscape review.}
