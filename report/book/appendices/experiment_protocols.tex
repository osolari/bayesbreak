
\chapter{Detailed experiment protocols}
\label{app:experiments}
\chapterpromise{Claim-mapped protocols that distinguish executed evidence, planned recertification, uncertainty, fairness, failure modes, and falsifying outcomes.}

\begin{statusbox}[Interpretation rule]
A protocol may contain both immutable executed outputs and planned expansion. Existing populated
values remain real computations; planned cells are never populated synthetically. Positive,
mixed, null, reversed, and falsifying outcomes must all be retained in the run registry.
\end{statusbox}

\section{Cross-protocol controls}
All simulations use deterministic seed registries and preserve ground truth separately from fitted
objects. Repetitions and intervals are predeclared. Comparator budgets, axes, penalties, and search
ranges are recorded before scoring. Data transforms are fitted on training data only. Runtime
studies separate block construction, DP, backtracking, prediction, and I/O. Every output is linked
to data/config/code hashes and a result ID.
