\paragraph{\texttt{bleakley2011groupfused}: \citet{bleakley2011groupfused}.}
Bleakley and Vert propose the group fused lasso for detecting changepoints shared across multiple one-dimensional signals by penalizing multidimensional total variation. It is a task-relevant frequentist comparator for common structural changes across sequences. BayesBreak differs by integrating sequence-specific segment parameters and, in its strict common-boundary model, multiplying sequence-level segment marginal likelihoods before Bayesian dynamic programming. The methods return different inferential objects, so comparisons must use comparable tuning budgets and distinguish point-estimate agreement from posterior uncertainty.
