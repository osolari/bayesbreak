
\paragraph{\texttt{corradin2026commonstructural}: \citet{corradin2026commonstructural}.}
Corradin, Danese, KhudaBukhsh, and Ongaro cluster time-dependent observations according to common structural-change locations using a latent random-order representation and Bayesian computation. This is the closest verified work for the broad latent-group narrative. BayesBreak retains only a narrower computational object: a finite collection of deterministic changepoint templates optimized under the explicitly stated criterion in Chapter~\ref{ch:templates}, using auxiliary allocation weights and exact responsibility-weighted max-sum updates. The two models should not be conflated, and no claim of first clustering by shared changepoints remains.
