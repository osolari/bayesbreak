\section*{Code and data availability}
The \BayesBreak Python package is available at
\href{\ProjectGitHub}{\texttt{github.com/osolari/bayesbreak}} and on PyPI
(\href{\ProjectPyPI}{\texttt{pip install bayesbreak}}).
The software release corresponding to this manuscript is archived at
\href{\ProjectDOIURL}{doi:\ProjectDOI}.
The implementation includes experiment drivers, dataset adapters, and
reproducibility specifications for all analyses reported here.
Public third-party datasets retain their original distribution and licensing
terms. No numerical results are imputed for the planned experiments in
Section~\ref{sec:experimental-design}.
