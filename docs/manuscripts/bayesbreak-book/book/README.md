# BayesBreak technical book

This source is the maintained technical book. It contains the mathematical background, algorithm derivations, hierarchical extensions, numerical approximations and empirical material. The canonical paper is `../paper/main.tex`, with shared references and graphics under `../shared/`. Build with `make -C docs/manuscripts book` from the repo root.

Book-wide consistency checking against the latest scientific corrections and any future verified experiment results remains open. Do not promote planned experiments to executed results. Consult `.claude/CURRENT_WORK.md` and `.claude/RESULT_POLICY.md` for current acceptance gates; the experimental configurations reside only in the repository skill.
