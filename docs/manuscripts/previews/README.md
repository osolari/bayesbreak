# Compiled manuscript previews

The paper and book PDFs in this directory are generated from the two maintained LaTeX entrypoints, `../paper/main.tex` and `../book/main.tex`. To reproduce the previews from the repository root, run `make -C docs/manuscripts paper book`. The paper is single-column. Scientific correctness and outstanding experiment acceptance are tracked in `.claude/CURRENT_WORK.md`; compilation does not mark unfinished experiments complete.
