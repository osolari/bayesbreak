
\paragraph{\texttt{muller2011ppmx}: \citet{muller2011ppmx}.}
M\"uller, Quintana, and Rosner introduce PPMx, adding covariate similarity to product-partition cohesion. This is direct lineage for data- or design-dependent partition priors. BayesBreak's contribution is a restricted ordered-contiguous factorization that makes segment cohesion and boundary hazard explicit and preserves exact normalization by dynamic programming. The source prevents claims that covariate-dependent or design-aware cohesion is new in general. \textit{Verification status: primary source checked in Phase 1.}
