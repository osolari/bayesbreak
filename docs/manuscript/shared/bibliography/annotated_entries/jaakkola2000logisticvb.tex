\paragraph{\texttt{jaakkola2000logisticvb}: \citet{jaakkola2000logisticvb}.}
Jaakkola and Jordan develop a variational bound for Bayesian logistic models. BayesBreak uses the construction only as an established segment-local approximation option for nonconjugate logistic marginal likelihoods or moments. The approximation is not a BayesBreak contribution, and the source does not supply a uniform segment-error rate for the present changepoint setting. Application of the BayesBreak posterior perturbation result therefore requires a separate, model-specific uniform bound over all reachable segments under explicit parameter, initialization, convergence, and tail conditions. \textit{Verification status: bibliographic metadata and DOI independently checked in Phase~6; the limitation on transferred error guarantees is retained.}
