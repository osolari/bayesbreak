
\paragraph{\texttt{fryzlewicz2014wbs}: \citet{fryzlewicz2014wbs}.}
Fryzlewicz introduces wild binary segmentation for efficient multiple-changepoint detection, especially when many changes may occur. It is a computationally attractive point-estimation baseline in the BayesBreak experiments. The source informs scaling and recovery comparisons, but it does not return the same posterior objects as BayesBreak. Archived F1 values computed against BayesBreak MAP boundaries are consequently labeled agreement diagnostics, not independent accuracy or evidence of superiority. \textit{Verification status: metadata retained; baseline use is explicit in the evidence ledger.}
