
\paragraph{\texttt{killick2012pelt}: \citet{killick2012pelt}.}
Killick, Fearnhead, and Eckley introduce PELT, a pruned optimization method with linear expected computational cost under stated conditions. PELT is a central efficiency comparator for BayesBreak's worst-case $O(k_{\max}n^2)$ exact posterior engine. The comparison is intentionally asymmetric in output richness: PELT targets a penalized optimal segmentation, whereas BayesBreak also returns evidence, segment-count uncertainty, boundary marginals, and model-averaged curves. Fair evaluation must match objectives and tuning budgets. \textit{Verification status: central primary source checked in Phase 1.}
