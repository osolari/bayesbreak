
\paragraph{\texttt{hutter2006bpcr}: \citet{hutter2006bpcr}.}
Hutter derives exact Bayesian regression for piecewise-constant functions, including unknown segment count and boundaries, evidence, break probabilities, error estimates, and a Bayesian regression curve. This is direct closest work for several BayesBreak headline outputs. The revised book therefore does not claim that evidence, boundary probabilities, or a Bayes curve originate with BayesBreak. The remaining contribution is the generalized use of exposure-aware segment sufficient statistics, shared and grouped extensions, separate posterior and joint-MAP calculations, and one implementation of these statistical quantities. \textit{Verification status: title, 2007 journal metadata, and DOI corrected in the project bibliography during Phase 1/3.}
