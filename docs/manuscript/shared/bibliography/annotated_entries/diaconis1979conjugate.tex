
\paragraph{\texttt{diaconis1979conjugate}: \citet{diaconis1979conjugate}.}
Diaconis and Ylvisaker characterize conjugate priors for exponential families. Their normalizer convention supplies the algebra behind BayesBreak's integrated block evidence: cumulative statistic contributions and cumulative log-partition multipliers update the conjugate hyperparameters, and the evidence is a ratio of normalizers times the powered base measure. BayesBreak extends the presentation with an exposure-aware descriptor $d_t$ and a separately declared power/reliability weight $a_t$ so Poisson exposures and binomial trial counts are not conflated with likelihood tempering. \textit{Verification status: bibliography metadata retained; mathematical use is explicit in Chapter~\ref{ch:block}.}
