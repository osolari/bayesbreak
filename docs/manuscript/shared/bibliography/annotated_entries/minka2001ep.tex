
\paragraph{\texttt{minka2001ep}: \citet{minka2001ep}.}
Minka develops expectation propagation as an approximate Bayesian inference method based on iterative moment matching. BayesBreak treats EP as one possible block-local evidence routine for a nonconjugate family. The revised method makes no routine-wide convergence or accuracy claim: EP must return diagnostics and, where global perturbation claims are desired, a certified error against a trustworthy reference on every reachable block. The source contributes the approximation mechanism, not evidence for BayesBreak-specific rates. \textit{Verification status: central source checked in Phase 1.}
