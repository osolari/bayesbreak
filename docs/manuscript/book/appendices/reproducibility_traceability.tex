\section{Traceability requirements}
Each scientific statement is linked to at least one of four sources of support: an in-place proof or exact derivation; an executed result that is valid for the stated interpretation; a verified external source; or an explicit statement that the proof or experiment remains planned. Whether a computation was executed is separate from whether it supports the stated scientific interpretation. Hashes identify source state; they do not establish correctness by themselves.

\section{Source hierarchy used for this book}
The source order is: integrity and the user's directive; approved Phase 2 decisions; editable
manuscript and real assets; compiled baseline; archived sidecars and implementation; Phase 1
verified literature; and explicitly labeled inference. Existing populated result values are never
modified by prose repair. Where source semantics conflict, the execution artifact is retained and
the interpretation is narrowed or excluded from the stated analysis.
