\subsection{Resource profile}

The work requires four coordinated roles, which may be held by fewer people when expertise overlaps:
\begin{itemize}
  \item a statistical-method lead to review priors, posterior prediction, approximation assumptions, metrics, and claim language;
  \item a scientific-software engineer to implement the task registry, schemas, tests, and result lineage;
  \item an empirical lead to run simulations and applications under fixed protocols and tuning budgets; and
  \item an independent reviewer for the final proof, numerical, comparator, and release checks.
\end{itemize}

The dominant computation is expected in repeated simulation, nonconjugate segment integration, and multi-sequence comparator studies. Exact resource estimates should be produced after the profiled test run and a small pilot of the expanded simulation grid; the current archive does not support a defensible fixed compute estimate.
