# BayesBreak presentation-source handoffs

These files define scientific content, evidence status, notation, citations, reusable assets, and narrative limits for a later presentation workflow. They do **not** contain slide source and do not authorize changes to the research title, method, results, or claim status.

- `shared/`: source of truth used by both routes.
- `technical/`: technical presentation content and an explicit prohibition on project or publication roadmaps.
- `executive/`: decision-oriented content and exact pointers to the two roadmaps already approved in the executive summary paper.
