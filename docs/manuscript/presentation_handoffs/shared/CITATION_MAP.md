# Citation map

Use citations to identify established lineages and the exact comparison, not as decorative name lists.

| Topic | Bibliography keys | Presentation use |
|---|---|---|
| Product-partition models and Bayesian changepoints | `barry1992ppm`, `barry1993bayesCP` | Define factorized partition priors and the Bayesian multiple-changepoint setting. |
| Exact Bayesian changepoint recursions | `fearnhead2006exact`, `hutter2006bpcr` | Position sum-product recursions and posterior computation over ordered partitions. |
| Conjugate exponential-family analysis | `diaconis1979conjugate`, `bernardo1994bayesian` | Support sufficient-statistic updating and analytic segment integration under proper conditions. |
| Online changepoint detection, outside the present scope | `adamsmackay2007bocpd` | Explain that BayesBreak is an offline finite-candidate method. |
| Reversible-jump methods, outside the exact finite recursion | `green1995rjMCMC` | Distinguish trans-dimensional simulation from the finite dynamic-programming formulation. |
| Alternative structural changepoint models | `ruggieri2014bcpvs` | Mark slope or variable-selection settings that require additional models. |

For every presentation citation, use the canonical metadata in `shared/bibliography/references.bib`. The book appendix `book/appendices/annotated_literature.tex` contains one project-specific annotation for every included bibliography entry.
