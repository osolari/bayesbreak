# Dataset cards

These cards declare source, coordinate, observation-family, descriptor, and
annotation semantics for the four application loaders. Runtime
`load_with_provenance(...)` records are versioned and hash the normalized arrays
actually returned after preprocessing and stride selection.

- [Array CGH](cgh.md)
- [SPX volatility](spx.md)
