# Manuscripts

The single-column paper is in [`docs/manuscripts/paper/main.tex`](https://github.com/osolari/bayesbreak/tree/main/docs/manuscripts/paper), and the companion technical book is in [`docs/manuscripts/book/main.tex`](https://github.com/osolari/bayesbreak/tree/main/docs/manuscripts/book). Both share a bibliography and figure assets in `docs/manuscripts/shared/`. Build either from the unified source with the Makefile in `docs/manuscripts/`.

The paper includes completed examples and explicitly Planned E00-E10 result slots. The book contains its mathematical background and extended methods. Future numerical updates must come from the same verified run records and are not inferred from old figures.
