# Reproducibility

## Package test profile

The current Phase 2 profile is recorded in
`provenance/test-manifest.json` and linked to the exact package-test
environment in `provenance/environment-lock.json`. On 2026-08-05 the current
suite collected 291 tests: 286 passed, five skipped because the optional
`ruptures` dependency was absent, and zero failed. Package coverage was 74%.

The historical Phase 6 EP node
`tests/test_families.py::test_ep_logistic_normal` no longer exists under that
ID, so its earlier 20-second timeout remains an unresolved lineage item rather
than a pass. Its two current successor nodes both pass the 20-second cap; the
manifest records their node IDs and measured times separately. MkDocs belongs
to a separate documentation profile and is not installed in the package-test
environment.

Every figure and table in §6 of the manuscript is regenerated by a
single script in `scripts/`. Every fit is cached to `.cache/fitcache/`
with a key derived from data hash + estimator parameters + bayesbreak
version, so re-renders are cheap.

## CLI

```bash
bayesbreak reproduce figures   # scripts/figures/*.py -> results/figures/
bayesbreak reproduce tables    # scripts/tables/*.py -> results/tables/
bayesbreak reproduce all
bayesbreak version
```

The CLI delegates to `bayesbreak.reproduce.reproduce(target)` —
importable from Python if you want to drive it programmatically.

## Fit cache (`.cache/fitcache/`)

Real-data fits are pickled to `<repo-root>/.cache/fitcache/`. Cache
payloads include the fitted estimator, the SHA-256-based cache key, the
wall-clock `runtime_s`, and a `ran_at` timestamp. The figure scripts
short-circuit when the cache hits the same key, so re-rendering the
figure layout costs seconds rather than re-fitting CGH for minutes.

Override the cache directory with `$BAYESBREAK_FITCACHE`; force a refit
with `BAYESBREAK_REFIT=1`. Cache files are gitignored.

## Verifying a clean checkout

```bash
git clone https://github.com/osolari/bayesbreak.git && cd bayesbreak
pip install -e ".[dev,plots,datasets,docs,notebooks]"
pre-commit install
pytest                       # 179+ tests, conceptual-correctness + sklearn contract
bayesbreak reproduce all     # writes new figures + tables under results/
make -C docs/manuscript validate-phase6         # rebuild and validate all manuscript targets
```

## What's reproducible without network

- Every synthetic figure (`fig1`–`fig5`) and every synthetic table
  (`table0`–`table4`).
- Every real-data fit when the cache is hydrated (see
  `.cache/fitcache/`).

## What needs network

- Fresh downloads in `load_welllog`, `load_cgh`, `load_spx`,
  `load_methylation` (with deterministic simulated fallbacks).
- The `bayesbreak[baselines-r]` extras (`rpy2` + R packages).
- `mkdocs gh-deploy` (writes to the `gh-pages` branch of the GitHub
  remote).
